# CITY EMPIRE — نسخهٔ گرافیکی وب متصل به ربات بله

این پروژه یک بازی شهرسازی ساده با رابط گرافیکی فارسی است. سرور Flask سایت را نمایش می‌دهد، وضعیت بازی را ذخیره می‌کند و پیام‌های ربات بله را با Bot API دریافت می‌کند.

## قابلیت‌ها
- تصویرسازی شهر فانتزی، قلعه، خانه‌ها و منابع با HTML/CSS (بدون نصب موتور بازی)
- جمع‌آوری مالیات، استخراج معدن، ساخت خانه و آموزش سرباز
- سپر دفاعی، جنگ با شهرهای دیگر و نبرد با اژدها
- سطح، XP، اعتبار، رویدادهای تصادفی و گزارش رویدادها
- ذخیرهٔ وضعیت بازیکن در فایل JSON
- فرمان `/start` و `/play` در ربات بله؛ لینک ورود امضاشده و زمان‌دار برای همان بازیکن
- توکن ربات فقط در متغیر محیطی سرور نگهداری می‌شود؛ هرگز آن را در JavaScript یا GitHub قرار ندهید

## اجرای محلی در ویندوز
در پوشهٔ پروژه، ترمینال VS Code را باز کن و اجرا کن:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
$env:APP_SECRET = "یک-رشته-تصادفی-طولانی-و-محرمانه"
$env:BALE_BOT_TOKEN = "توکن-جدید-ربات-بله"
python app.py
```

سایت محلی در `http://127.0.0.1:5000` باز می‌شود. اما ربات نمی‌تواند لینک `localhost` را روی دستگاه کاربر باز کند؛ برای اتصال واقعی باید سایت روی یک نشانی عمومی HTTPS قرار بگیرد و متغیر `GAME_URL` همان نشانی باشد.

## انتشار ساده با Render
1. کل پوشهٔ پروژه را در یک مخزن GitHub بارگذاری کن؛ `data/players.json` و توکن را بارگذاری نکن.
2. در Render از **New + → Blueprint** مخزن را انتخاب کن تا `render.yaml` خوانده شود؛ یا یک Web Service پایتون بساز.
3. متغیرها را تنظیم کن:
   - `BALE_BOT_TOKEN`: توکن جدیدی که از BotFather در بله گرفته‌ای.
   - `APP_SECRET`: یک راز طولانی و تصادفی که ثابت بماند.
   - `GAME_URL`: نشانی عمومی HTTPS سایت، مثلاً `https://your-service.onrender.com` (با دامنهٔ خودت جایگزین کن).
4. پس از Deploy، آدرس `/health` را باز کن؛ باید `ok: true` نشان دهد.
5. در بله به ربات پیام `/start` بده و سپس `/play` را بفرست. دکمهٔ ورود به نسخهٔ گرافیکی ظاهر می‌شود.

## نکات مهم
- توکن قبلی‌ات در کدی که پیش‌تر فرستادی آشکار شده بود. آن را باطل کن و فقط توکن تازه را در `BALE_BOT_TOKEN` قرار بده.
- فایل JSON برای نمونه و تست مناسب است. در هاست رایگان، فایل‌ها ممکن است پس از راه‌اندازی مجدد پاک شوند؛ برای حفظ مطمئن پیشرفت، از دیسک پایدار یا پایگاه دادهٔ PostgreSQL استفاده کن.
- برای جلوگیری از اجرای چند حلقهٔ polling، این سرویس با یک worker اجرا می‌شود. اگر تعداد بازیکن‌ها زیاد شد، بات و سایت را به دو سرویس جدا و ذخیره‌سازی را به پایگاه داده منتقل کن.
- بازی آنلاین می‌شود، اما این نسخه هنوز رقابت زنده/چندنفرهٔ هم‌زمان ندارد؛ امتیاز و وضعیت هر بازیکن با شناسهٔ چت بله جدا می‌شود.
